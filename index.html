What Transformer FFNs never see

A feed-forward layer only receives a mixture of value vectors. Two attention patterns can manufacture the exact same mixture, so the layer cannot tell which tokens it used. A short trace of the attention weights makes those patterns separable again.

The collision is structural.

Each head compresses n attention weights into a shorter value mixture. When the sequence is longer than that mixture, different routes are forced to share an output. The feed-forward layer then sees identical inputs and must produce identical outputs. Making the network deeper, wider, or more trained does not put the discarded weights back.

The missing trace is already computed.

The attention weights exist earlier in the same forward pass. Route-Aware FFN keeps a few summaries of them — how peaked the distribution is, and which positions carry the mass — and adds that vector to the mixture before the feed-forward layer. The original mixture stays. The routes no longer look the same.

Four summaries recover the route.

They are computed from the same attention as the figure above. The mixture stays on one vector. The summaries move with the route, and name which tokens carry it.
